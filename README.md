# Photoshop

Десктопное приложение для обработки растровых изображений, разработанное на **C#** с использованием **Avalonia UI** и **SkiaSharp**.

---

## Описание

Photoshop предоставляет удобный графический интерфейс для открытия, просмотра и применения различных фильтров и преобразований к растровым изображениям. Поддерживается предпросмотр результата обработки, сравнение с оригиналом и сохранение результата в файл.

---

## Возможности

### Интерфейс

- Меню, панель инструментов и область просмотра изображения
- Граница области просмотра всегда отображается пунктирной линией, в том числе до загрузки изображения
- Область просмотра масштабируется вместе с окном приложения
- Все кнопки на панели инструментов имеют всплывающие подсказки
- Все действия на панели инструментов продублированы в меню
- Диалоговое окно «О программе» с информацией об авторе и приложении

### Просмотр изображений

- Открытие файлов форматов **PNG, JPEG, BMP, GIF**
- **Режим реального размера** — отображение пиксель к пикселю; если изображение меньше области просмотра — незанятое пространство заполняется нейтральным цветом; если больше — доступна прокрутка и перемещение по изображению зажатием мыши
- **Режим «подогнать под экран»** — изображение вписывается в область просмотра с сохранением пропорций; по умолчанию используется **билинейная интерполяция** (режим интерполяции можно изменить в настройках)
- Переключение между режимами через панель инструментов или меню
- Сохранение результата обработки в файл формата **PNG**

### Сравнение оригинала и результата

После применения любого фильтра можно переключаться между **обработанным изображением** и **оригиналом** кликом по изображению или через меню. Каждый фильтр всегда применяется к оригинальному изображению, а не к результату предыдущей обработки.

## Инструменты обработки изображений

### Базовые преобразования

| Инструмент | Описание |
|---|---|
| Оттенки серого | Перевод цветного изображения в чёрно-белое |
| Негатив | Инверсия цветов изображения |
| Гамма-коррекция | Настройка яркости с параметром γ от 0.1 до 10 |
| Поворот | Поворот изображения на произвольный угол от −180° до +180° относительно центра; фон — белый |

### Фильтры размытия и резкости

| Инструмент | Описание |
|---|---|
| Гауссово размытие | Сглаживание по окну от 3×3 до 11×11 (нечётный размер); для окон 7×7 и больше применяется усреднение |
| Повышение резкости | Фильтр увеличения чёткости |
| Акварелизация | Художественный эффект акварельного рисунка |

### Выделение границ

| Инструмент | Описание |
|---|---|
| Оператор Робертса | Выделение границ методом Робертса с настраиваемым порогом бинаризации |
| Оператор Собеля | Выделение границ методом Собеля с настраиваемым порогом бинаризации |
| Тиснение | Эффект рельефного тиснения |

### Дизеринг

| Инструмент | Описание |
|---|---|
| Дизеринг Флойда–Стейнберга | Диффузия ошибки с настраиваемым числом уровней квантования для каждого канала (R, G, B) от 2 до 128 |
| Упорядоченный дизеринг | Дизеринг на основе матрицы Байера с автоматически определяемым размером матрицы и настраиваемым числом уровней квантования для каждого канала от 2 до 128 |
